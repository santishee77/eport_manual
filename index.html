ภาพรวมและวิธีใช้เอกสารนี้

สร้างเพื่ออธิบายระบบ `v_` ของ `mod/newmodule` แบบใช้จริง, อ่านง่าย, และแก้ต่อได้ง่าย

ขอบเขต

  • หน้าจอหลักของ `v_` ทั้งกลุ่ม dashboard, management, report, detail view
  • ไฟล์ helper / API ที่ช่วยให้หน้าจอทำงาน
  • ตารางฐานข้อมูลที่เกี่ยวข้อง และความสัมพันธ์ที่ควรรู้
  • DFD, ER, และ use case สำหรับอ้างอิงต่อยอด

วิธีอ่านเอกสาร

  1. เริ่มจากแผนที่หน้าจอ เพื่อรู้ว่าแต่ละไฟล์ทำอะไร
  2. อ่านหน้าจอที่ใช้จริงก่อน แล้วค่อยไปส่วน technical reference
  3. เวลาเพิ่มรูป, วางรูปใต้ placeholder ของหน้าจอนั้นเลย
  4. ถ้าจะพิมพ์ PDF, ใช้ปุ่ม Print / Save PDF หรือ `Ctrl+P`
เอกสารนี้ตั้งใจให้ portable คือใช้ชื่อไฟล์และหัวข้อเป็นหลัก, ไม่ผูกกับ path เครื่องใดเครื่องหนึ่ง. ถ้าจะย้ายไป server อื่น, ให้ยกทั้งโฟลเดอร์คู่มือไปพร้อมกันได้เลย.

Troubleshooting / Logs

สิ่งที่ควรตรวจเมื่อหน้าเว็บเละ, ขึ้น error, หรือดึงข้อมูลไม่ได้

อาการ สาเหตุที่ควรเช็คก่อน สิ่งที่ควรดู
Missing parameter เช่น `id` / `setid` / `sid`เปิด page โดยไม่ส่ง query string ที่จำเป็นURL, form action, redirect logic
Could not connectDB connection external ผิด user / password / host / portconfig DB, network, credentials
`dataroot is not configured properly`Moodle config หรือ folder permission ผิดconfig.php, dataroot path, permission
ONLY_FULL_GROUP_BY errorSQL legacy query ต้องปรับ grouping หรือ aggregatequery ที่ SELECT หลายคอลัมน์ร่วมกับ GROUP BY
Definer not foundview / routine ใช้ definer ที่ไม่มีอยู่ใน server นี้definitions ของ view และ routine
หน้าขาว / blank pagePHP fatal error หรือ include หายApache error log, PHP error log, debug output
CSS เละ / layout แตกmissing include, footer, หรือ stylesheet ไม่ถูกโหลดbrowser devtools, page wrapper, footer call

Log ที่ควรเปิดดู

  • Apache error log
  • PHP error log
  • Moodle debug output ถ้าเปิดไว้
  • Browser console ถ้าหน้าใช้ JS / AJAX

กติกาเวลาทำงานกับหน้าจอจริง

  • อย่าพึ่งสร้าง table หรือไฟล์ใหม่ถ้า data เดิมยังใช้ได้
  • อย่าฝัง SQL ซ้ำหลายจุดถ้า helper reuse ได้
  • ถ้าเจอ error จาก query, แก้แบบไม่กระทบหน้าที่ไม่เกี่ยวข้อง
